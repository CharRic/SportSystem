# 南联微信支付真实闭环部署清单

当前代码默认关闭真实支付。完成以下配置及小额验收前，不得把 `PAYMENT_PRODUCTION_ENABLED` 设置为 `true`。

## 1. HTTP支付通知入口

在微信云开发/CloudBase控制台为 `clubApi` 云函数配置HTTP访问服务，建立一个仅用于微信支付通知的公开POST路径，例如：

```text
https://<正式云环境HTTP域名>/wechat-pay/notify
```

将最终可公网访问的完整HTTPS地址填入 `WECHAT_PAY_NOTIFY_URL`。该路径进入 `clubApi` 后，由HTTP事件分支直接交给微信支付通知处理器，不经过小程序登录态。

部署后必须用无签名POST验证接口返回4xx，不能返回业务成功；再用微信支付真实通知完成验签、解密和幂等验收。

## 2. 云函数环境变量

必须在正式云环境配置，禁止写入仓库或小程序前端：

```text
WECHAT_PAY_APPID
WECHAT_PAY_MCHID
WECHAT_PAY_PRIVATE_KEY
WECHAT_PAY_SERIAL_NO
WECHAT_PAY_PUBLIC_KEY_ID
WECHAT_PAY_PUBLIC_KEY
WECHAT_PAY_API_V3_KEY
WECHAT_PAY_NOTIFY_URL
PAYMENT_PRODUCTION_ENABLED
```

`WECHAT_PAY_APPID` 必须为当前项目AppID `wx6082ff5e4a142c74`。第一轮部署保持：

```text
PAYMENT_PRODUCTION_ENABLED=false
```

## 3. 数据集合

部署 `clubApi` 后确认以下集合已建立，并禁止小程序端直接写入：

```text
payments
paymentTransactionClaims
paymentSecurityLogs
orders
lessonEntitlements
lessonEntitlementEvents
lessonLedger
auditLogs
```

## 4. 开启前验收

1. 先运行支付自动化回归。
2. 部署云函数和HTTP访问路径。
3. 检查管理员端支付状态仍为“未就绪”。
4. 配置真实商户参数，保持生产开关关闭。
5. 使用受控内测账号完成小额真实支付。
6. 核对微信商户订单、`orders`、`payments`、课时权益、`lessonLedger`和Audit Log一致。
7. 重复发送/重放同一合法通知，确认课时只到账一次。
8. 全部通过后才将 `PAYMENT_PRODUCTION_ENABLED` 改为 `true` 并重新部署。
