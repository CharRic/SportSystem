# 南联青训正式测试版部署与验收

## 当前版本范围

正式测试版只保留以下业务：账号与角色、班级、报名、课程、点名、请假、课时、教练与课程双绑定定价、订单、优惠券、新闻公告、站内通知和运营汇总。

已从小程序入口和云函数路由中移除 CRM、线索、体验课、联赛、成长档案、精英选拔、训练评价和旧续费套餐。旧云数据库集合不会被代码自动删除，避免误删历史数据；确认不再需要后，应先导出备份，再在云开发控制台手动删除。

## 部署步骤

1. 在微信开发者工具确认项目 AppID 与云环境 `cloud1-d2g4gi77g48dcee01` 属于同一小程序。
2. 右键 `cloudfunctions/clubApi`，选择“上传并部署：云端安装依赖”。不要再次新建同名函数。
3. 编译小程序。首次调用时云函数会创建缺少的集合，并初始化默认课程类型。
4. 在云开发控制台为高频查询建立索引；索引未建时数据量较小仍可测试，数据增长后必须补齐。

建议索引：

- `users`: `openid` 唯一索引。
- `classes`: `classCode` 唯一索引；`status + createdAt`。
- `classMembers`: `classId + studentId + status`；`studentId + status`。
- `sessions`: `classId + date`；`status + date`。
- `attendance`: `sessionId + studentId` 唯一索引；`studentId + date`。
- `leaveRequests`: `sessionId + studentId + status`；`status + submittedAt`。
- `orders`: `orderNo` 唯一索引；`userId + createdAt`；`status + createdAt`。
- `notifications`: `targetUserId + createdAt`。
- `pricingRules`: `coachId + courseTypeId + status`。
- `coupons`: `code` 唯一索引。

## 上线前身份测试

在 `clubApi` 云函数环境变量中设置 `BOOTSTRAP_ADMIN_OPENIDS` 和 `TEST_ROLE_SWITCH_OPENIDS`，值为获准账号的 OPENID；多个 OPENID 用英文逗号分隔。白名单账号进入“我的”后，可在管理员、教练员、学员端之间切换，同一个微信账号即可完成三种身份验收。

正式发布前必须删除云函数环境变量 `TEST_ROLE_SWITCH_OPENIDS` 并重新部署。`BOOTSTRAP_ADMIN_OPENIDS` 应保留真实管理员 OPENID，不能使用“首个访问者自动成为管理员”的规则。

## 微信支付配置

云函数采用微信支付 APIv3 JSAPI 下单，所有密钥只能配置在 `clubApi` 云函数环境变量中，不能写入小程序代码或数据库：

- `WECHAT_PAY_APPID`
- `WECHAT_PAY_MCHID`
- `WECHAT_PAY_SERIAL_NO`
- `WECHAT_PAY_PRIVATE_KEY`
- `WECHAT_PAY_PUBLIC_KEY_ID`
- `WECHAT_PAY_PUBLIC_KEY`
- `WECHAT_PAY_API_V3_KEY`
- `WECHAT_PAY_NOTIFY_URL`

没有这些商户资料时，可以测试课程定价、优惠券、创建订单和管理员手工确认到账，不能完成真实微信付款。当前版本在用户支付后由云函数查询微信支付订单，只有微信返回 `SUCCESS` 才增加课时；管理员手工确认仅作为测试或线下收款通道。

正式开放线上支付前，还应把 `WECHAT_PAY_NOTIFY_URL` 接到已验证签名并解密报文的支付回调服务，同时配置定时对账，覆盖“用户付款后立即关闭小程序”的情况。回调和主动查询都必须保持幂等，重复通知不能重复加课时。

## 推荐验收顺序

1. 管理员：创建班级并绑定自己作为测试教练；创建课程类型、双绑定价格和优惠券；发布新闻。
2. 教练员：用自己的账号创建班级；或使用管理员生成的绑定班级邀请码注册；发布签到并审批本班请假。
3. 学员端：直接注册学员；按班级号、班级名或教练搜索报名；验证满员后不可报名。
4. 点名：教练开启签到并设置地点；学员输入 6 位校验码并授权定位；再测试教练名单勾选。
5. 请假：学员提交，教练和管理员查看审批；验证站内通知与缺勤提醒。
6. 订单：创建订单、应用优惠券；未配置微信支付时由管理员手工确认；确认课时只增加一次。
7. 运营后台：核对收入、订单数、出勤率和待审批请假。
